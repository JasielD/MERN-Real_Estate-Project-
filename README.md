## 📍 Overview

<code>This Real Estate web application allows users to browse, search and view property listings. It also provides an admin interface (or back-end API) to manage listings, upload property images, and handle user requests.  
The goal is to demonstrate a modern full-stack implementation with React on the front end, Node/Express on the back end, and MongoDB as the database, styled with Tailwind CSS for a clean UI.</code>

---

## 👾 Features

<code>
- Browse property listings with images, details, and filters  
- Upload property images
- RESTful API routes for CRUD operations on listings  
- Responsive UI via Tailwind CSS  
- Secure server setup with environment variables and middleware  
- Real-world folder structure separating routes/controllers/models/utils 
</code>

---

## 💻 Tech Stack  
- **Front End:** React, Tailwind CSS  
- **Back End:** Node.js, Express.js  
- **Database:** MongoDB (via Mongoose)  
- **Other:** Multer (for file uploads), dotenv (for environment config), CORS, etc.

## 🚀 Getting Started

### ☑️ Prerequisites

Before getting started with MERN-Real_Estate-Project-, ensure your runtime environment meets the following requirements:

- **Programming Language:** JavaScript
- **Package Manager:** Npm


### ⚙️ Installation

Install MERN-Real_Estate-Project- using one of the following methods:

**Build from source:**

1. Clone the MERN-Real_Estate-Project- repository:
```sh
❯ git clone https://github.com/JasielD/MERN-Real_Estate-Project-
```

2. Navigate to the project directory:
```sh

```

3. Install the project dependencies:


**Using `npm`** &nbsp; [<img align="center" src="https://img.shields.io/badge/npm-CB3837.svg?style={badge_style}&logo=npm&logoColor=white" />](https://www.npmjs.com/)
